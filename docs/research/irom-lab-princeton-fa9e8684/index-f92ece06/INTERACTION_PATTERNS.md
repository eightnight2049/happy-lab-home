# Interaction patterns

- Navigation links: `180ms cubic-bezier(.2,.7,.3,1)` color/background transitions.
- Primary CTA: accent red at rest, deep red on hover.
- Ghost CTA: transparent with semi-transparent white border over the hero; solid white border on hover.
- Cards: translate upward `3px` and gain a soft shadow on hover.
- Slideshow: timer-driven, pauseable, and keyboard accessible through native buttons.
- Forms: red focus ring using the accent-soft token; all writes are performed by explicit submit actions.
