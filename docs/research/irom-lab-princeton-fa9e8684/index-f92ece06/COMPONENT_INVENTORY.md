# Component inventory

- `SiteHeader`: shared sticky public navigation and responsive mobile menu.
- `HeroCarousel`: visual hero, CTA group, slideshow controls, pause state.
- `NewsList`: dated updates and expand/collapse behavior.
- `PublicationList`: search, filters, year grouping, external link chips.
- `PeopleGrid` / `PersonAvatar`: roster cards and profile lead card.
- `SiteFooter`: contact and site-admin links.
- `AdminDashboard`: login, role-aware navigation, overview metrics, site settings, news publishing, publication upload/draft creation, people directory, and role policy.
